# Ajaia Collaborative Docs

A lightweight collaborative document editor built with React and Express.

## Development

```bash
npm install
npm run dev
```

The frontend runs at `http://localhost:5173` and the backend API at
`http://localhost:3001`.

## Scripts

- `npm run dev` — run both applications
- `npm run build` — build both applications
- `npm run typecheck` — type-check both applications
- `npm test` — run backend tests
